# 0.10.0 验收记录

日期：2026-10-03。宿主为官方源码构建的 Harness 0.2.0-rc.2（639ed01），使用 E 盘隔离 DSH_HOME 与本机 CalDAV 测试服务，账号和日程均为合成数据。

## 浏览器实际操作

在官方设置页完成了以下流程：

- 用原生文件选择器选择 ICS，再用粘贴方式加载相同内容；未标注时区的日程被阻止，明确选择 Asia/Shanghai 后显示正确时间。
- 预览识别目标日历中位于 2020 年的同 UID 日程，证明检查不局限于当前月。重复系列与改期例外作为一条导入项显示；未知时区给出修正指引。
- 关闭预览后服务器收到 0 次写入；预览不会自动选中日程，必须勾选后确认。
- 确认三条新日程，服务端对其中一条模拟一次 503：两条成功、一条失败；界面重试只提交失败项，最终三条成功。共 4 次 PUT，所有请求均带 If-None-Match: *。
- 再次预览时四个已有 UID 全部禁选；成功项目没有再次写入。存储结果保留主记录、RRULE、EXDATE、RECURRENCE-ID 与 VTIMEZONE，并移除参与者。
- 预览后通过连接表单切换集合，旧导入计划显示“日历连接已改变，请重新预览”，PUT 总数保持 4。
- 390 × 844 视口下，导入面板内容宽与滚动宽均为 330px，没有水平溢出。服务商凭据说明明确区分日历授权与模型 API 密钥；未配置模型密钥也能使用面板。

## 自动测试范围

新增 11 项导入回归覆盖重复系列与 DST、主记录顺序、文件自带时区隔离、UTC 与浮动时间、异常日期与时区、邀请和提醒处理、完整 UID 检查、部分失败重试、连接变更与过期、取消与并发、认证路由来源校验、UID 文件名隔离。完整 191 项 Windows 测试、TypeScript 检查及客户端语法检查通过。

本地 tarball 在新建消费目录安装成功；6 个原有模型工具与导入认证路由正常登记，安装后的面板预览解析及文档链接检查通过。Google/iCloud 的生产账号业务仍未验证。

## 未验证与限制

本轮没有向真实 Google、iCloud 或 Nextcloud 账号导入日程，也没有在原生桌面窗口内操作新功能。浏览器操作与本机 HTTP 传输验收不能替代这些测试。

重叠提示只检查系列首场；PERIOD 类型的 RDATE、缺少主记录的例外、缺少 DTSTART 的取消例外与 METHOD:CANCEL 文件暂不支持。文件、批次与目标日历大小限制详见[使用说明](../USAGE.md#导入-ics-日程)。
